# PMS FastAPI 版部署文档

基于 **Python 3.10+ / FastAPI / Uvicorn / PyMySQL / MySQL 8.0** 的项目管理系统 FastAPI 版。
这是纯 REST API 实现（无服务端页面），提供交互式文档 `/docs`，与 Spring Boot / Gin 版共用数据库表和 Token 契约。

---

## 一、系统功能

- API Token 认证（HMAC-SHA256，签名格式见 `../db/API.md`）
- 工作台统计：`/api/dashboard`
- 项目 CRUD、成员管理、进度计算
- 任务 CRUD、三列看板排序、执行人指派
- 用户管理：仅管理员可操作 `/api/users`
- 自动建表与默认管理员初始化

## 二、目录结构

```
pms-fastapi/
├── requirements.txt                 # Python 依赖
├── .env.example                     # 环境变量示例
├── start.sh                         # 便捷启动（开发模式，带 --reload）
├── 部署文档.md                        # 本文
├── sql/schema.sql                   # 建表脚本副本（与 db/schema.sql 一致）
└── app/
    ├── main.py                      # 应用入口、全部 API 路由
    ├── config.py                    # 配置加载（环境变量优先，其次 .env）
    ├── db.py                        # PyMySQL 连接与建表初始化
    ├── security.py                  # Token 签发/校验、BCrypt 口令
    └── schemas.py                   # Pydantic 请求模型
```

## 三、环境准备

| 软件 | 版本要求 | 备注 |
|------|---------|------|
| Python | 3.10+ | 本机 venv 为 3.13，已验证 |
| MySQL | 8.0+（5.7 亦可） | 与其他版共用库 |
| Nginx（生产可选） | 1.18+ | 反向代理 / HTTPS |

### 1. 创建数据库

```bash
mysql -u root -p
```

```sql
CREATE DATABASE pms DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'pms'@'%' IDENTIFIED BY 'your-password';
GRANT ALL PRIVILEGES ON pms.* TO 'pms'@'%';

```

## 四、部署步骤

### 1. 创建虚拟环境并安装依赖

```bash
cd pms-fastapi
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
cp .env.example .env
vim .env
```

生产环境务必修改：

```ini
DB_NAME=pms
DB_USER=pms
DB_PASSWORD=your-password
DB_HOST=127.0.0.1
DB_PORT=3306

SERVER_PORT=8000

API_SECRET=换成与另两版相同的随机长字符串
ADMIN_USERNAME=admin
ADMIN_PASSWORD=换成强密码

CORS_ORIGINS=https://your-frontend.com   # 生产建议限定具体来源，不要用 *
```

> `API_SECRET` 必须与 Spring Boot / Gin 版一致，Token 才能跨版本互认。
> 系统环境变量优先于 `.env`（`config.py` 用 `setdefault`，已存在的环境变量不会被覆盖）。

### 3. 本地开发运行

```bash
./start.sh
# 或
.venv/bin/uvicorn app.main:app --reload --port 8000
```

- 接口文档：<http://127.0.0.1:8000/docs>（Swagger UI）与 `/redoc`
- OpenAPI 规范：`/openapi.json`
- 启动时 lifespan 自动执行 `sql/schema.sql` 幂等建表，`users` 表为空则创建默认管理员。

## 五、生产环境部署（Linux + systemd + Nginx）

### 1. 部署目录与依赖

```bash
sudo mkdir -p /opt/pms-fastapi
sudo cp -r pms-fastapi/. /opt/pms-fastapi/
cd /opt/pms-fastapi
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

生产不用 `--reload`，用多 worker 的 gunicorn（需额外安装 `gunicorn`）：

```bash
.venv/bin/pip install gunicorn
```

### 2. systemd 服务

`/etc/systemd/system/pms-fastapi.service`（Uvicorn 单进程版）：

```ini
[Unit]
Description=PMS FastAPI Service
After=network.target mysql.service
Wants=mysql.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/opt/pms-fastapi
EnvironmentFile=-/opt/pms-fastapi/.env

ExecStart=/opt/pms-fastapi/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000

KillSignal=TERM
TimeoutStopSec=30
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

若用 gunicorn 多 worker，把 `ExecStart` 换成：

```ini
ExecStart=/opt/pms-fastapi/.venv/bin/gunicorn app.main:app \
  -w 4 -k uvicorn.workers.UvicornWorker -b 127.0.0.1:8000
```

> 多 worker 时每个进程启动都会跑一次 `init_db()`；`schema.sql` 是幂等的（`CREATE TABLE IF NOT EXISTS`），管理员创建前会检查 users 表是否为空，不会重复创建。

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now pms-fastapi
sudo systemctl status pms-fastapi
journalctl -u pms-fastapi -f
```

### 3. Nginx 反向代理

`/etc/nginx/conf.d/pms-fastapi.conf`：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    client_max_body_size 10M;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

HTTPS 在此层终止。生产建议把 `/docs`、`/redoc`、`/openapi.json` 限制在内网或加认证：

```nginx
    location ~ ^/(docs|redoc|openapi.json)$ {
        allow 10.0.0.0/8;
        deny all;
        proxy_pass http://127.0.0.1:8000;
    }
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### 4. 更新发布

```bash
cd /opt/pms-fastapi
git pull
.venv/bin/pip install -r requirements.txt
sudo systemctl restart pms-fastapi
```

## 六、常见问题排查

| 问题 | 解决方法 |
|------|---------|
| `ModuleNotFoundError` | 确认已 `source .venv/bin/activate` 且 `pip install -r requirements.txt` |
| `Access denied` / 连不上库 | 检查 `.env` 的 DB_*；确认 MySQL 账号权限与来源主机 |
| `Unknown database 'pms'` | 先执行第三节建库 SQL |
| API 401 | 检查 `Authorization: Bearer <token>`；三版 `API_SECRET` 需一致；Token 24 小时过期 |
| 跨域被浏览器拦截 | 调整 `CORS_ORIGINS` 为实际前端来源，多个用逗号分隔 |
| 端口被占用 | `lsof -nP -iTCP:8000 -sTCP:LISTEN`，或用 `SERVER_PORT` 改端口 |
| 与 Django 版端口冲突 | Django 默认也是 8000，两版同时启动需给其中一版设不同的 `SERVER_PORT` |
| `/docs` 打不开 | 确认不是被 Nginx 规则拦截；或检查服务是否正常启动 |

```bash
curl -s http://127.0.0.1:8000/openapi.json | head -c 120
TOKEN=$(curl -s -X POST http://127.0.0.1:8000/api/auth/login \

curl -s http://127.0.0.1:8000/api/dashboard -H "Authorization: Bearer $TOKEN"
```
