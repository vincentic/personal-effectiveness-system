# PMS React 共享前端

React 19 + TypeScript 单页应用，功能、API 契约和响应式界面与 [Vue 共享前端](../../vue/pms-vue/)一致，可连接 FastAPI、Gin API、Spring Boot API 或 Flask API。该目录只包含前端，不包含业务 API 或数据库服务。

本地开发、测试和 API 连接见[搭建指南](../../../docs/projects/react/pms-react/setup.md)，构建说明见[构建过程讲解](../../../docs/projects/react/pms-react/build-process-explained.md)，静态站点发布见[部署指南](../../../docs/projects/react/pms-react/deployment.md)。

通用 REST API 契约见[API 契约](../../../docs/data/api-contract.md)；项目根目录的 [README](../../../README.md) 提供所有后端和前端项目的搭建指南索引。
