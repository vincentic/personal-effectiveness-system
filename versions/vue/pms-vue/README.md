# PMS Vue 共享前端

Vue 3 + TypeScript 单页应用，可连接 FastAPI、Gin API、Spring Boot API 或 Flask API。该目录只包含前端，不包含业务 API 或数据库服务。

本地依赖安装、API 连接和开发步骤见[搭建指南](../../../docs/projects/vue/pms-vue/setup.md)，构建流程见[构建过程讲解](../../../docs/projects/vue/pms-vue/build-process-explained.md)，静态站点和 FastAPI 同源发布见[部署指南](../../../docs/projects/vue/pms-vue/deployment.md)。

通用 REST API 契约见[API 契约](../../../docs/data/api-contract.md)；项目根目录的 [README](../../../README.md) 提供所有后端和前端项目的搭建指南索引。
