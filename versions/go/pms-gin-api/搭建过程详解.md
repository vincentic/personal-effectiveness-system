# Gin REST API 搭建过程详解

本文介绍如何启动独立的 Go/Gin REST API，并将共享 Vue 前端连接到它。该项目不渲染业务页面；服务端页面版见 [`../pms-gin/`](../pms-gin/搭建过程详解.md)。

## 1. 环境准备

- Go 1.22 或更高版本。
- MySQL 8.0 或更高版本。
- Node.js 与 npm（仅在本地开发或构建 Vue 前端时需要）。

从仓库根目录创建数据库：

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS pms CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

应用启动时会执行项目内嵌的 `sql/schema.sql` 幂等建表脚本。数据库要先创建，建表由服务启动过程完成。

## 2. 配置并启动 API

```bash
cd versions/go/pms-gin-api
cp .env.example .env
```

编辑 `.env` 设置 MySQL 的 `DB_HOST`、`DB_PORT`、`DB_NAME`、`DB_USER`、`DB_PASSWORD`。`API_SECRET` 用于 HMAC Token 签名；若需与 Spring Boot API、FastAPI 共享 Token，三者必须使用相同密钥。生产环境请替换模板中的开发密钥。

首次启动且 `users` 表为空时，`ADMIN_USERNAME` / `ADMIN_PASSWORD` 会创建初始管理员；默认仅适合本地开发。`SERVER_PORT` 默认是 `8081`。独立部署 Vue 时，将实际前端来源设置到 `CORS_ORIGINS`，多个来源以逗号分隔。

启动 API：

```bash
go run .
```

## 3. 启动共享 Vue 前端

另开一个终端，在仓库根目录执行：

```bash
cd versions/vue/pms-vue
npm ci
VITE_API_PROXY_TARGET=http://127.0.0.1:8081 npm run dev
```

访问 Vite 输出的本地地址。开发代理会把 `/api` 和 `/health` 请求转发给 Gin API；浏览器因此无需直接跨域访问后端。若只检查 API，可参考共享契约 [`../../../db/API.md`](../../../db/API.md) 并调用认证、健康或业务端点。

## 4. 验证与构建

在 Gin API 目录执行：

```bash
go test ./...
go build ./...
```

Vue 前端的单测、类型检查和生产构建可在 `versions/vue/pms-vue` 执行：

```bash
npm test
npm run typecheck
npm run build
```

Gin API 不会托管 Vue 构建产物；生产部署时分别部署 API 和前端，并配置实际的 CORS 来源，或使用反向代理将其置于同一来源。

## 5. 常见问题

- **Token 无法跨 API 版本使用**：检查 Gin、Spring Boot、FastAPI 的 `API_SECRET` 是否完全一致。
- **Vue 请求被浏览器拦截**：本地优先使用 Vite 代理；独立部署时检查 `CORS_ORIGINS` 与前端 origin。
- **数据库连接或建表失败**：先确认数据库存在，再检查 MySQL 账号权限和 DB_* 配置。
- **管理员账号无法登录**：初始管理员只在 `users` 表为空时创建；已有数据库不会重置用户密码。
- **开发端口冲突**：Gin API 默认 `8081`；通过 `SERVER_PORT` 修改 API 端口，并同步调整 `VITE_API_PROXY_TARGET`。
