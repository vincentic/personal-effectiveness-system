# 个人效能系统 · 使用指南（简体中文）

本指南帮助你用系统落地「日执行 → 周复盘 → 月重构」的效能闭环。系统包含 Django、Go/Gin、Java/Spring Boot、FastAPI 和 Flask 实现，并提供 Vue 与 React 两套共享前端：Gin、Spring Boot、Flask 提供服务端页面，Django 提供 Session 页面，FastAPI 可同源托管 Vue 与 REST API。

## 1. 登录与双端切换

1. 打开所选用版本的根地址（Django `:8000/`、Spring Boot `:8080/`、Gin `:8081/`、Flask 页面版 `:8001/`；FastAPI 构建前端后访问 `:8000/`；React 开发页为 `:5174/`），输入管理员或你的账号密码登录。
2. **Django / Spring Boot / Gin 双端**：系统按浏览器 User-Agent 自动选择 PC 版或手机版。手机上打开会看到适配触屏的移动界面。
3. **前三版手动切换**：
   - PC 版顶栏点「📱 手机版」切到移动版；
   - 手机版顶栏点「🖥 PC 版」切回电脑版，底部还有「自动」恢复按设备判断。
   - 选择会保存在浏览器 cookie（有效期一年），下次打开保持你的偏好。
   - 切换会重新载入当前页面；未保存的表单输入会丢失，切换前请先保存。

4. **FastAPI 页面**：PC 与手机共用 Vue 3 响应式页面；手机上导航会折叠为菜单。页面由 FastAPI 同源提供，`/docs` 是交互式 API 文档。
5. **React 页面**：功能与 Vue 版一致，可独立部署并连接任一兼容 API；开发时默认使用 `http://127.0.0.1:5174/`。

## 2. 每日执行清单（每天早上 3 分钟 + 晚上 5 分钟）

进入「每日执行」，点「填写今日清单」。页面分五个区：

1. **今日方向**：填日期、睡眠小时、精力（低/中/高），写下**今天最重要的一个成果（MIT）**——先决定成果，再安排时间。
2. **今日组块与时间盒**：为 2–4 个组块各填「组块/任务、时间盒起止、输入、关键动作、可验收输出」。时间盒结束检查进度即可，不要求强行做完。可勾选完成。
3. **执行前后检查**：启动前 3 项（知道交付什么/材料已备/通知已处理）、执行中 3 项（一次一组块/卡住缩小下一步/记录干扰）、结束后 3 项（有可见产出/主动回忆/标记下一步）。
4. **生活维护**：饮水饮食、运动、清洁整理、真实交流户外——不追求满分，保持基本盘。
5. **晚间复盘**：今天真正完成了什么、最大阻力、明天最小启动动作、值得感谢的一件事。

保存后回到列表，可查看每日组块进度（完成数/总数）与检查完成度。Django 可在列表直接勾选时间盒完成状态；Gin、Spring Boot 和 Flask 可进入编辑表单修改完成状态。页面版均可编辑或删除记录。

**要点**：MIT 只有一个；每个组块必须有可验收输出；晚间复盘回答"真正完成"而非"计划完成"。

## 3. 每周复盘清单（每周 30–45 分钟）

进入「每周复盘」，点「填写本周复盘」。四个区：

1. **本周回顾**：按工作/项目、学习/技能、身体/精力、关系/生活四个领域，用**事实而非感觉**填写产出，并标注状态（顺利/受阻/暂停）。
2. **任务流清理**：把任务分到待办、进行中、已完成、删除/委托/延后四栏——重点是给任务流出货口，别只进不出。
3. **下周设计**：写下下周最多 1–3 项最重要成果、要保护的深度时间（日期/时段）、需提前准备的环境材料，以及一个 If–Then 计划（"如果……那么我就……"）。
4. **复盘问题**：逐条确认——哪个组块更熟练、哪件事耗时多价值低、哪个时间盒估算偏差最大、本周有无休息快乐连接、下周继续/调整/停止什么。

**要点**：周复盘大于周计划；目标是让下周更清楚、更轻、更有效，而不是排得更满。

## 4. 每月重构清单（每月 45–60 分钟）

进入「每月重构」，点「填写本月重构」。四个区：

1. **目标与价值检查**：本月最重要成果、它是否仍值得投入（是/调整/停止 + 原因）、本月最有价值投入、本月最大机会成本。
2. **系统健康检查**：给方向清晰度、任务负荷、组块质量、时间盒现实程度、睡眠体能情绪、复盘反馈质量六个模块各打 1–5 分，并写下需要的改变。工作台会显示平均分。
3. **下月三项改进**：只写三项——保留（有效的）、删减（低价值的）、实验（新的最小改变）。
4. **季度方向校准**（可选）：技能是否形成作品、工作是否接近长期方向、生活是否更有自主性、是否有足够恢复与关系投入、是否应继续/转向/停止某项长期投资。

**要点**：系统的最终标准是——重要事情持续推进、生活基本盘稳定、注意力有自主权、系统本身不成为负担。

## 5. 多版本说明与数据共享

Gin、Spring Boot、FastAPI 与 Flask 使用 `db/schema.sql` 定义的共享 v2 表结构，数据按账号隔离；Django 使用自己的 ORM 迁移实现对应业务实体。FastAPI、Spring Boot、Gin 和 Flask API 遵循相同的 API Token 契约；页面版使用各自的会话机制。

- **页面用户**：通过 Session / 签名 Cookie 登录，数据按账号隔离，看不到别人的清单。
- **API 用户**：Vue / React 前端和程序调用都通过 `POST /api/auth/login` 获取 Token，并在 `Authorization: Bearer <token>` 中携带。四种 API 实现的 Token 可互通。完整端点见 [API 契约](../data/api-contract.md)。
- 默认端口：Spring Boot 8080、Gin 8081、Django / FastAPI 8000、Flask 页面版 8001、Flask API 版 8002、Vue 5173、React 5174。

## 6. 常见问题

**Q：切换手机/电脑版会丢数据吗？**
不会。切换只改显示模板与浏览器偏好，不改数据。但当前页未点击「保存」的输入不会被自动保存。

**Q：一天/一周/一月能填多条吗？**
不能。系统对（账号，日期/周/月）做了唯一约束，一天一条日清单、一周一条周复盘、一月一条月重构。要修改请编辑已有记录。

**Q：明细项（时间盒、领域、任务流、健康项）怎么保存？**
它们随主清单一同保存。编辑时改动明细行，点保存后会整体替换旧明细——不需要单独保存每一项。

**Q：忘记了某天的数据怎么办？**
在每日执行列表点「填写今日清单」，日期选过去的某天即可补录；但同一天已有记录时需编辑那条。

**Q：手机上内容看不全？**
Django / Spring Boot / Gin 使用独立移动模板；Flask、Vue 和 React 页面使用响应式布局。页面内容会随屏幕宽度调整。

**Q：可以同时多人用吗？**
可以，数据按账号隔离。用户管理仅管理员可操作（在 `/admin/users/` 或对应页面）。

## 7. 使用节奏建议

- 早晨：3 分钟写 MIT 与时间盒；
- 每个时间盒结束：30 秒勾选 + 检查；
- 晚上：5 分钟复盘四问；
- 每周固定 30–45 分钟：周复盘；
- 每月固定 45–60 分钟：月重构。

坚持一个季度后，用月重构的"系统健康"分数变化与周复盘的"继续/调整/停止"来判断系统是否在为你服务。
