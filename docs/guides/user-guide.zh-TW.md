# 個人效能系統 · 使用指南（繁體中文）

本指南協助你落實「日執行 → 週復盤 → 月重構」的效能閉環。四個實作版本共用資料模型；Django、Spring Boot、Gin 提供電腦版／手機版頁面，FastAPI 提供 Vue 3 響應式頁面與 REST API。

## 1. 登入與雙端切換

1. 開啟所選版本的根網址（Django `http://127.0.0.1:8000/`、Spring Boot `:8080/`、Gin `:8081/`；FastAPI 完成前端建置後為 `:8000/`），輸入帳號密碼登入。
2. **Django / Spring Boot / Gin 雙端**：系統依瀏覽器 User-Agent 自動選擇電腦版或手機版，手機上會顯示適合觸控的行動介面。
3. **前三版手動切換**：
   - 電腦版頂欄點「📱 手機版」切到行動版；
   - 手機版頂欄點「🖥 電腦版」切回電腦版，底部另有「自動」回復依裝置判斷。
   - 選擇會儲存在瀏覽器 cookie（有效期一年），下次開啟保持偏好。
   - 切換會重新載入目前頁面；未儲存的表單輸入會遺失，切換前請先儲存。

4. **FastAPI 頁面**：電腦與手機共用 Vue 3 響應式頁面；手機導覽會折疊為選單。頁面由 FastAPI 同源提供，`/docs` 是互動式 API 文件。

## 2. 每日執行清單（早上 3 分鐘 + 晚上 5 分鐘）

進入「每日執行」，點「填寫今日清單」。頁面分五個區：

1. **今日方向**：填日期、睡眠時數、精力（低/中/高），寫下**今天最重要的一項成果（MIT）**——先決定成果，再安排時間。
2. **今日組塊與時間盒**：為 2–4 個組塊各填「組塊/任務、時間盒起訖、輸入、關鍵動作、可驗收產出」。時間盒結束檢查進度即可，不要求強行做完。可勾選完成。
3. **執行前後檢查**：啟動前 3 項（知道交付什麼/材料已備/通知已處理）、執行中 3 項（一次一組塊/卡住先縮小下一步/記錄干擾）、結束後 3 項（有可見產出/主動回憶/標記下一步）。
4. **生活維護**：飲水飲食、運動、清潔整理、真實交流或戶外——不追求滿分，保持基本盤。
5. **晚間復盤**：今天真正完成了什麼、最大阻力、明天最小啟動動作、值得感謝的一件事。

儲存後回到列表，可查看每日的組塊進度（完成數/總數）與檢查完成度。Django 可在列表直接勾選時間盒完成狀態；Gin、Spring Boot 和 FastAPI 可在編輯表單修改完成狀態。四版皆可編輯或刪除紀錄。

**要點**：MIT 只有一個；每個組塊必須有可驗收產出；晚間復盤回答「真正完成」而非「計畫完成」。

## 3. 每週復盤清單（每週 30–45 分鐘）

進入「每週復盤」，點「填寫本週復盤」。四個區：

1. **本週回顧**：依工作/專案、學習/技能、身體/精力、關係/生活四個領域，用**事實而非感覺**填寫產出，並標註狀態（順利/受阻/暫停）。
2. **任務流清理**：把任務分到待辦、進行中、已完成、刪除/委託/延後四欄——重點是給任務流出貨口，別只進不出。
3. **下週設計**：寫下下週最多 1–3 項最重要成果、要保護的深度時間（日期/時段）、需提前準備的環境材料，以及一個 If–Then 計畫（「如果……那麼我就……」）。
4. **復盤問題**：逐條確認——哪個組塊更熟練、哪件事耗時多價值低、哪個時間盒估算偏差最大、本週有無休息快樂與真實連結、下週繼續/調整/停止什麼。

**要點**：週復盤大於週計畫；目標是讓下週更清楚、更輕、更有效，而不是排得更滿。

## 4. 每月重構清單（每月 45–60 分鐘）

進入「每月重構」，點「填寫本月重構」。四個區：

1. **目標與價值檢查**：本月最重要成果、它是否仍值得投入（是/調整/停止 + 原因）、本月最有價值投入、本月最大機會成本。
2. **系統健康檢查**：為方向清晰度、任務負荷、組塊品質、時間盒現實程度、睡眠體能情緒、復盤回饋品質六個模組各打 1–5 分，並寫下需要的改變。工作台會顯示平均分。
3. **下月三項改進**：只寫三項——保留（有效的）、刪減（低價值的）、實驗（新的最小改變）。
4. **季度方向校準**（選填）：技能是否形成作品、工作是否更接近長期方向、生活是否更有自主性、是否有足夠恢復與關係投入、是否應繼續/轉向/停止某項長期投資。

**要點**：系統的最終標準是——重要事情持續推進、生活基本盤穩定、注意力有自主權、系統本身不成為負擔。

## 5. 四版說明與資料共享

Django / Spring Boot / Gin / FastAPI 四版共用同一個資料庫與效能表結構，資料依帳號隔離。FastAPI 與 Spring Boot / Gin 共用 API Token 契約；頁面版各自使用不同的工作階段機制。

- **頁面使用者**：透過 Session / 簽名 Cookie 登入，資料依帳號隔離，看不到別人的清單。
- **FastAPI 頁面與 API 使用者**：頁面登入後由瀏覽器保存目前工作階段 Token。程式呼叫可用 `POST /api/auth/login` 取得 Token，並在 `Authorization: Bearer <token>` 中攜帶；FastAPI、Spring Boot、Gin 的 Token 可互通。完整端點見 [API 契約](../data/api-contract.md)。
- 預設連接埠：Spring Boot 8080、Gin 8081、FastAPI 8000；Django 與 FastAPI 同為 8000，同時啟動時需錯開。

## 6. 常見問題

**Q：切換手機/電腦版會丟資料嗎？**
不會。切換只改變顯示模板與瀏覽器偏好，不改資料。但當前頁未點「儲存」的輸入不會自動儲存。

**Q：一天/一週/一月能填多筆嗎？**
不能。系統對（帳號，日期/週/月）設有唯一約束，一天一筆日清單、一週一筆週復盤、一月一筆月重構。要修改請編輯既有紀錄。

**Q：明細項（時間盒、領域、任務流、健康項）怎麼儲存？**
它們隨主清單一同儲存。編輯時改動明細列，點儲存後會整體取代舊明細——不需單獨儲存每一項。

**Q：忘記某天的資料怎麼辦？**
在每日執行列表點「填寫今日清單」，日期選過去某天即可補錄；但同一天已有紀錄時需編輯該筆。

**Q：手機上內容看不全？**
Django / Spring Boot / Gin 使用獨立行動模板；FastAPI Vue 頁面採用響應式版面與折疊導覽，內容會配合螢幕寬度調整。

**Q：可以多人同時使用嗎？**
可以，資料依帳號隔離。使用者管理僅管理員可操作（在 `/admin/users/` 或對應頁面）。

## 7. 使用節奏建議

- 早晨：3 分鐘寫 MIT 與時間盒；
- 每個時間盒結束：30 秒勾選與檢查；
- 晚上：5 分鐘回答四題復盤；
- 每週固定 30–45 分鐘：週復盤；
- 每月固定 45–60 分鐘：月重構。

堅持一季後，用月重構的「系統健康」分數變化與週復盤的「繼續/調整/停止」來判斷系統是否為你服務。
