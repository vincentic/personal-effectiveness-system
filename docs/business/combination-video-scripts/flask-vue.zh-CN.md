# 《Flask API + Vue 组合应用》中文口播稿

> **预计时长**：约 18 分钟（含页面与代码演示），不超过 30 分钟
> **组合分支**：`release/flask-vue`
> **服务端口**：Flask API 8002；Vue 开发服务器 5173

## 00:00–02:00｜开场

**画面**：展示 Vue 页面、Flask API 目录和 MySQL。

**旁白**：

大家好，这段视频介绍 Flask REST API 与 Vue 前端的组合。Vue 是独立的单页应用，Flask 提供 JSON API。页面和后端可以分开发布，也可以由 Nginx 统一提供同源入口。Flask API 默认监听 8002，Vue 开发服务器默认监听 5173。

系统帮助用户完成每日执行、每周复盘和每月重构。我们会从用户需求开始，沿着 Vue 表单、HTTP 请求、Flask 校验和 MySQL 保存，说明一个功能如何跨越前后端。

## 02:00–05:00｜需求与功能

**画面**：展示每日时间盒、周复盘领域和月度健康检查。

**旁白**：

每日流程记录 MIT、精力、执行检查和时间盒；每周流程回顾工作、学习、身体、关系，整理任务流并设定下周成果；月度流程检查目标价值、机会成本和系统健康。工作台提供当前周期概要。

验收不能只看表单可见。新增的记录必须可读取，编辑后明细必须正确替换，删除后子记录要清理。系统还要拒绝重复日期、周起始日和月份，并限制跨账号读取。无效输入要返回可理解错误，而不是静默丢弃。

## 05:00–09:00｜Flask 与 Vue 架构

**画面**：高亮 Vue → Flask :8002 → PyMySQL → MySQL。

**旁白**：

Flask API 项目位于 `versions/python/pms-flask-api`，使用 Flask 路由处理 REST 请求，Pydantic schema 校验输入，PyMySQL 访问数据库。Vue 项目位于 `versions/vue/pms-vue`，开发代理默认转向 8002。

API 登录后签发 HMAC Token，Vue 的 API 客户端为后续请求添加 Bearer Token。服务端从已验证的身份获取当前用户，再按所有权过滤数据。数据库中，日、周、月主表分别关联时间盒、领域事实和健康检查等明细。

Flask API 与 Flask 页面单体版是不同项目。当前组合只讨论 Flask API，不要用服务端页面的 Session 路由替代 REST 端点。生产部署建议使用 Gunicorn 运行 Flask，并通过 Nginx 处理 TLS 和代理；不要直接把开发服务器暴露到公网。

## 09:00–13:00｜业务演示

**画面**：启动 Flask API 与 Vue，保存每日计划并检查 API 响应。

**旁白**：

先安装 Python 依赖，配置 `.env` 中的数据库地址、API_SECRET 和管理员账号；然后准备 Vue 依赖并启动前端。演示账号登录后，新增一条每日清单，填写 MIT 和时间盒。保存后检查列表和详情，再修改输出并完成一个组块。

随后创建周复盘，填入一个工作领域事实和任务流，保存后重新读取。使用另一测试账号尝试访问该记录，确保数据没有泄露。最后发送一个非法状态值，确认 Flask API 返回校验错误，并且数据库没有成功形状的部分记录。

Flask API 的自动化测试位于 `tests/test_api.py`，依赖开发测试环境；前端 Vue 项目包含 API 客户端测试、类型检查和构建。代码讲解可以先看 `app.py` 路由，再看 Pydantic schema、数据库辅助函数和前端 `api.ts`。

## 13:00–16:00｜验收管理

**画面**：展示 API 测试计划、Vue 构建和手机页面检查。

**旁白**：

验收矩阵分为 Flask API、Vue 页面、MySQL 和部署四层。API 层覆盖登录、权限、日周月 CRUD、重复周期、非法字段和错误码；前端覆盖 5 项 API 客户端测试、响应式页面和表单状态；数据库层检查唯一键和级联关系；部署层检查 Gunicorn、健康路由、CORS、密钥和 Nginx。

每次发布要关联需求编号、测试结果、提交号和 Release。若某项测试没有执行，记录“待验证”并说明原因，不能把计划当成通过结果。

## 16:00–18:00｜反馈与扩展

**画面**：展示问题报告示例和后续架构选项。

**旁白**：

建议试用者报告具体操作、预期和实际结果，附上应用版本和设备信息。不要提交 Token、密码或真实个人记录。当前产品没有内置反馈入口，需由团队选择受控渠道并按严重程度跟踪。

扩展 API 时要保持 Pydantic schema、Flask 路由、数据访问与 Vue 类型一致；扩展报表时先定义计算口径和权限；扩展提醒或集成时再设计外部服务失败和重试策略。以上就是 Flask API + Vue 的组合应用。
