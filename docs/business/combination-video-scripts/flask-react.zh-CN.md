# 《Flask API + React 组合应用》中文口播稿

> **预计时长**：约 18 分钟（含页面与代码演示），不超过 30 分钟
> **组合分支**：`release/flask-react`
> **前端包管理**：pnpm

## 00:00–02:00｜开场

**画面**：展示 React 页面、Flask API 和两个项目目录。

**旁白**：

大家好，本片介绍 Flask API 加 React 前端的个人效能系统。Flask 负责 REST API、认证和数据库读写；React 负责登录、工作台、日周月清单以及响应式交互。前后端独立构建，使用 JSON 与 Bearer Token 连接。

这套组合适合希望以轻量 Python 服务提供数据、用 TypeScript 管理前端类型的团队。业务流程仍围绕每日执行、每周复盘和每月重构，不因框架替换而改变。

## 02:00–05:00｜需求分析

**画面**：展示三个周期表单，并标注关键业务字段。

**旁白**：

每日清单通过 MIT 和时间盒把成果拆成行动；周复盘记录四领域事实、状态、任务流和下周计划；月度重构记录成果、继续投入的理由、机会成本和系统健康。工作台将当前周期数据整理成概览。

系统还要处理边界：同一用户同一周期只能有一条主记录；每条子记录归属于主记录；用户不能查看其他账号数据；无效请求要明确失败。我们用正常流程、错误流程和权限流程共同验收，而不是只录一段成功保存的视频。

## 05:00–09:00｜架构和数据流

**画面**：展示 React :5174 → Flask API :8002 → MySQL。

**旁白**：

Flask API 项目位于 `versions/python/pms-flask-api`，默认端口 8002，使用 Pydantic 描述输入并由 PyMySQL 执行数据库操作。React 项目位于 `versions/react/pms-react`，依赖由 pnpm 锁定，Vite 默认端口 5174，此分支代理到 Flask API。

React 的 API 客户端集中添加 Authorization 头、处理 JSON 和 401。Token 只用于当前浏览器会话；真正的权限仍由 Flask 服务端验证 Token 并确定当前用户。每次读写都需检查所有者，不能因为前端隐藏了按钮就认为权限已经保护。

数据模型采用主表加明细表。比如每周复盘主记录连接领域事实和任务流；日记录连接多个时间盒；月记录连接健康检查。主表唯一约束防止重复周期，外键确保明细不能脱离主记录。

## 09:00–13:00｜页面与代码演示

**画面**：pnpm 安装、Flask 启动、React 保存周复盘。

**旁白**：

准备 MySQL 和 Python 环境，安装 Flask API 依赖并配置环境变量。进入 React 工程执行 `pnpm install --frozen-lockfile`，然后分别启动 Flask API 和 React Vite 页面。

登录后创建每日清单，填写一个 MIT 和两个时间盒。保存后回到列表检查数据，再编辑第二个时间盒的输出。随后创建周复盘，添加一个身体领域的事实和一条待办任务。刷新页面重新打开，确认数据仍然存在。

演示时再尝试非法枚举、重复周期和跨账号读取。页面端的提示要易理解，API 端的响应码和错误语义要符合约定。代码追踪从 React View 到 `api.ts`，再到 Flask 路由、Pydantic schema 和数据库辅助函数。

## 13:00–16:00｜验收与质量管理

**画面**：展示 React 测试、lint/typecheck/build、Flask API 测试文件。

**旁白**：

React 侧包含 5 项 API 客户端测试、ESLint、类型检查和生产构建；Flask API 项目提供 `tests/test_api.py`，可在安装开发测试依赖后运行。两侧测试不能互相替代：mock 前端测试不证明 Flask 的真实权限和数据库行为。

验收还应验证 MySQL 的唯一键、用户隔离、错误回滚、Gunicorn 启动、CORS 来源和 HTTPS。为每项需求保留测试证据、版本号和问题记录。生产发布前检查密钥注入和数据库备份，发布后观察健康状态和错误日志。

## 16:00–18:00｜反馈与后续扩展

**画面**：展示用户反馈表、API 契约及未来增强路线。

**旁白**：

用户反馈要描述“做了什么、在哪里卡住、希望发生什么”。建议收集任务完成率、错误提示是否清楚、手机表单是否顺手等观察，不直接收集完整个人清单。反馈采集由项目管理流程承担，当前系统没有内置反馈模块。

后续可增加可视化趋势、导出或管理员功能。每次扩展都要明确权限、数据保留、接口兼容和迁移策略，并更新 React 类型、Flask schema、数据库结构和测试。以上就是 Flask API 与 React 的组合介绍。
