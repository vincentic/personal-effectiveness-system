# 《FastAPI + Vue 同源组合应用》中文口播稿

> **预计时长**：约 18 分钟（含页面与代码演示），不超过 30 分钟
> **组合分支**：`release/fastapi-vue`
> **服务端口**：FastAPI 8000；Vue 开发服务器 5173

## 00:00–02:00｜开场

**画面**：展示浏览器地址栏、FastAPI 页面和 `/docs`。

**旁白**：

大家好，这段视频介绍 FastAPI 加 Vue 的同源组合。Vue 是独立的前端工程，但生产构建后输出到 FastAPI 的静态页面目录。FastAPI 在 8000 端口同时提供页面和 REST API。这样生产环境可使用单一站点来源，减少前后端跨域配置。

用户使用系统完成每日执行、每周复盘和每月重构。即使采用同源部署，前后端的职责仍然分开：浏览器负责交互，FastAPI 负责认证、数据校验和存储，MySQL 保存记录。

## 02:00–05:00｜需求与功能

**画面**：依次展示工作台、每日清单、周复盘和月度重构。

**旁白**：

每日表单围绕 MIT 和时间盒，支持执行前中后检查和晚间复盘。每周页面记录四领域事实、状态、任务流和下周计划。月度页面记录成果、价值判断、保留删减实验及系统健康评分。工作台展示当前周期和近期数据。

功能还要遵守两类规则：同一账号在同一周期只能有一条主记录；任何读取或修改都要限定在当前账号。API 对日期、枚举、分数和明细数组进行校验。验收既要看页面能否使用，也要直接检查 API 是否拒绝不合法请求。

## 05:00–09:00｜FastAPI 与 Vue 的架构

**画面**：高亮 Vue 源码、Vite build 输出目录、FastAPI `app/web` 与 MySQL。

**旁白**：

FastAPI 项目位于 `versions/python/pms-fastapi`，Vue 项目位于 `versions/vue/pms-vue`。开发时，Vue 通过 Vite 将 `/api` 请求代理到 8000；生产构建时，Vue 静态文件写入 FastAPI 的 `app/web`，FastAPI 从同源提供页面和 API。

后端使用 Pydantic 描述请求字段，路由通过认证依赖获取当前用户，数据库访问由 PyMySQL 完成。`/docs` 提供交互式 API 文档，`/health` 可用于健康探测。Vue 的 API 客户端保存会话 Token 并在请求中添加 Bearer 头。

同源部署简化了浏览器来源和代理配置，但并没有消除安全要求。仍要为生产配置强随机 API_SECRET、HTTPS、数据库最小权限账号和安全的管理员密码。构建步骤还必须在应用启动前完成，否则后端没有可服务的前端文件。

## 09:00–13:00｜演示构建和业务操作

**画面**：展示前端 build 命令、FastAPI 启动、`/` 和 `/docs`。

**旁白**：

先创建 MySQL 数据库，再建立 Python 虚拟环境并安装 FastAPI 项目依赖。Vue 工程使用其锁文件安装依赖，然后执行生产构建。构建输出写入后端 `app/web`。启动 FastAPI 后访问根路径，浏览器应加载 Vue 页面；访问 `/docs` 可以查看 API 文档。

登录后新建一个每日计划，添加两个时间盒，保存并刷新页面确认数据从 API 读回。接下来新增周复盘，填写四领域中的一项事实及任务流。编辑时删掉一条明细再保存，观察接口约定的整体替换行为。最后进入月度重构，填写健康评分，确认工作台摘要对应实际数据。

画面讲解代码时，先从 Vue View 看表单，再沿 API 客户端找到 HTTP 请求；后端则从 FastAPI route、Pydantic schema 到 SQL 访问逐层追踪。前端类型检查不能替代后端校验，直接构造非法 JSON 的请求也要被正确拒绝。

## 13:00–16:00｜验收与风险管理

**画面**：展示 Vite 构建产物、FastAPI 文档和验收矩阵。

**旁白**：

前端验收应包括单元测试、类型检查、构建和浏览器冒烟；后端验收包括启动、认证、API 契约、数据库 CRUD、重复周期和跨账号用例。FastAPI 的数据库操作需要特别确认事务边界：如果主记录和明细分开提交，某一步失败时可能出现不完整数据，不能仅凭成功路径判定原子性。

发布时记录 Python 依赖、前端锁文件、构建输出、环境变量和 MySQL 版本。真实部署要确认静态资源能从根路径加载，API 路由未被 SPA fallback 截获，健康检查和日志不泄漏 Token。没有真实 MySQL 环境的验证应标成待环境验收。

## 16:00–18:00｜反馈与扩展

**画面**：展示试用反馈表及跨域/同源两种拓扑。

**旁白**：

试用者可以反馈页面是否找得到、填写是否顺畅、保存后是否能确认结果。记录浏览器、设备、步骤和预期，不收集真实个人清单。当前系统没有内置反馈入口，建议通过项目 issue 或受控问卷管理。

后续可考虑用 React 替代 Vue 页面，增加统计图表，或将静态资源交给 CDN；但需要重新定义构建产物和路由回退规则。任何数据库变化都要经过迁移和备份设计。以上就是 FastAPI 与 Vue 同源组合的使用和交付要点。
